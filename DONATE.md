# Support This Work

Thanks for checking out these indicators.

Everything in this repository is free to use. There is no paywall, no premium tier, and no required payment. You can clone it, study it, and run the scripts on TradingView without donating.

If the tools have been useful and you want to help keep the work going, voluntary support is welcome. Even a small amount helps cover time spent building, testing, and documenting new ideas.

Using the indicators, starring the repo, opening issues, or sharing feedback already counts as support.
